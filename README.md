# Flask DevOps API

Projeto desenvolvido para a disciplina DevOps na Prática.

## Tecnologias

- Python
- Flask
- Pytest
- Docker
- GitHub Actions
- Terraform
- Amazon Web Services
- Amazon EC2

## Endpoints

| Método | Endpoint | Descrição |
|---|---|---|
| GET | `/` | Informações da aplicação |
| GET | `/health` | Health check |
| GET | `/version` | Versão da aplicação |

## Executar localmente

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
python -m app.main
